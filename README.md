# UselessThings
没用的东西mod（wip）

Minecraft模组，版本1.20.1（forge）

目前添加了以下物品：
* 可以无限生长，能够结出可以生成建筑的“建筑花”方块的“建筑绿植”
* 能够无限侵蚀世界的彩虹液体“虹水”以及对应的桶
* 能够使周围找出各种花朵的植物法杖
* 能够使玩家获得所有正面/中性/负面效果的buff和对应药水
* 能够把普通村民变成傻子村民以及对流浪商人有特殊效果的喷雾器
* 能够捅马蜂窝或者帮别人捅的棍子
* 能够秒杀山羊并锯下山羊角的锯子
* 一个能无限加载区块然后崩掉游戏的区块加载器
* 一个把石头全改成泥土的镜像世界（按F24进入）
* 将DeepSeek's Enchant的世界树移植后改为树苗并拥有了6向种植的能力以及特殊的黄金骨粉
* 把时间变成负树的转换器
* 看上去装逼特效一堆实际上不咋样的手持王冠
由于是半成品，还没定好究竟用MIT还是CC4.0，所以暂时不打算添加协议文件

没有英文语言文件（en_US），这只是个半成品，我也不知道最后会不会正式完成，也可能做到一半就弃坑，具体就看各位的反馈了
